# MD Viewer

نرم‌افزار دسکتاپ نمایش فایل‌های Markdown با پشتیبانی کامل RTL، ساخته‌شده با Electron، React و TypeScript.

## امکانات

- نمایش فایل‌های Markdown (با پسوند `.md` و `.markdown`)
- پشتیبانی کامل RTL برای متن فارسی/عربی
- نمایش خودکار بخش‌های کد و متن انگلیسی به صورت LTR
- حالت تیره (Dark Mode)
- تعیین به عنوان نرم‌افزار پیش‌فرض باز کردن فایل‌های `.md`
- پشتیبانی از GFM (جدول، تسک‌لیست و...)

## توسعه

```bash
npm install
npm run electron:dev
```

## ساخت نسخه نهایی

```bash
npm run electron:build
```

نصب‌کننده ویندوز در پوشه `release/` ساخته می‌شود که فایل‌های `.md` را به عنوان نرم‌افزار پیش‌فرض ثبت می‌کند.
